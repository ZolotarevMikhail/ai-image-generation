# Генерация изображений по тексту (нейромедиа)

Примеры работ: изображения в жанре «макро-миниатюры» — крошечные человечки в крупном человеческом мире. Каждая картинка сгенерирована ИИ по текстовому промпту и доработана до рекламной/концептуальной сцены.

## Работы

| Файл | Сцена |
|---|---|
| `images/mini-people-laptop.png` | Мини-персонал «подключает» старшее поколение к онлайн-сервису: маленькие операторы тянут провода к деревянному ноутбуку с кнопкой START TEST |
| `images/mini-people-keyboard.png` | Очередь мини-людей к ретро-монитору: пользователи стоят на клавиатуре, на экране неоновая надпись START TEST |

Промпты хранятся в `images/промпты.md`.

## Как посмотреть

Картинки открываются двойным кликом (или смотрите папку `images/` выше на странице GitHub).

## Что это для демонстрации

Показ возможностей: по короткой идее («мини-человечки и онлайн-тест») делается законченная сцена с освещением, композицией и смыслом — для соцсетей, баннеров, постов.

## Технологии

- Генерация изображений ии по текстовым промптам (стиль: макро-миниатюры, toy-like);
- Ручной отбор и кадрирование.

## Лицензия

Изображения — работы автора репозитория, сгенерированные по собственным промптам.
